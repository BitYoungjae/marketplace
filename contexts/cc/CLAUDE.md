# contexts/cc/

Claude Code 관련 참조 문서 및 학습 기록 디렉토리.

## 파일 구조

- `*.md` - 공식 문서 동기화 (`scripts/cc-docs-sync.sh`)
- `lesson-learned.md` - 실험/경험 통해 배운 것들

## lesson-learned.md 작성 규칙

새로운 항목 추가 시:

1. **파일 끝에 추가** (기존 `---` 구분선 아래)
2. **형식**:
   ```markdown
   ## 카테고리명

   ### 항목 제목

   **결론**: 한 줄 요약

   **상세 내용** (필요시):
   - 공식 문서 인용
   - 동작 방식
   - 대안/해결책
   - 예시

   ---
   ```
3. **간결하게**: 핵심만 기록, 실험 과정은 생략
4. **검증된 것만**: 추측이 아닌 확인된 사실만 기록
